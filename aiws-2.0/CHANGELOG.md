# Changelog

## 0.3.0 — 2026-11-03

- Schema 2: native arrays, nested records and null state with bounded JSON validation.
- Immutable, version-preserving migration of legacy dataset strings, bindings and actions.
- Native data workspace and structured state type/record editing.
- Atomic row append/form clearing, filtered row removal, required-field validation and undo/redo.
- People / CRM example with desktop/mobile example selection and dynamic workspace labels.
- Recursive canonical addresses avoid rebuilding for record key reordering.
- 44 unit/integration tests plus desktop/mobile/offline browser workflows.

## 0.2.0 — 2026-11-03

- Graph-defined scalar state, bindings and deterministic event dispatch with consumer validation.
- Semantic binding/event/move operations, numeric metrics and boolean visibility.
- Search and reporting-period interactions in Northstar; independent counter example.
- Component management, binding/event authoring, graph import and offline HTML app export.
- Version-preserving local restore, complete session history and keyboard undo/redo.
- English/German compound commands with explicit unsupported-request handling.
- Responsive layout improvements and desktop/mobile/offline browser tests.
- Restricted local asset server, reproducible CI and updated architecture documentation.

Initial imported Kernel & Studio archive, strict TypeScript core, atomic patches, retained DOM rendering, redo, local persistence and benchmark foundation.
